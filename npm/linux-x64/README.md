# @reachpad/cli-linux-x64

The [reachpad](https://reachpad.dev/docs/cli) CLI binary for Linux on x86-64,
built from public source for the `x86_64-unknown-linux-musl` target.

This package exists so that `npm install -g @reachpad/cli` fetches one
binary instead of four. Install that instead:

```sh
npm install -g @reachpad/cli
```

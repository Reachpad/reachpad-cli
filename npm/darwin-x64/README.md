# @reachpad/cli-darwin-x64

The [reachpad](https://reachpad.dev/docs/cli) CLI binary for macOS on Intel,
built from public source for the `x86_64-apple-darwin` target.

This package exists so that `npm install -g @reachpad/cli` fetches one
binary instead of four. Install that instead:

```sh
npm install -g @reachpad/cli
```
